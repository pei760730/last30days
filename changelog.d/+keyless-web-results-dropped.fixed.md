Keyless web search results are no longer silently discarded on evergreen topics. `normalize_source_items` requires a publish date for `grounding` items, but the keyless SERP floor (the headless/cron path, used whenever no paid search key is set) never returns one — so 100% of what it retrieved was dropped and every run reported `Web: 0 results` while the brief still claimed the web was consulted. When the planner has already decided the topic is `evergreen_ok`, undated web results are now kept; they carry `date_confidence="low"` so ranking still discounts them. Items with a *known* date outside the window stay dropped, unchanged.
